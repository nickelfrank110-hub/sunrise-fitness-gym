# Sunrise Fitness Gym

A fictional gym landing page with membership plans and testimonials, built with HTML and CSS.

🔗 **Live demo:** https://nickelfrank110-hub.github.io/sunrise-fitness-gym/

## Features
- Hero section with a "Join Now" button that scrolls to the contact section
- Services, membership plans (priced in KSh), and testimonials
- Tappable phone and email contact links
- Hover effect on the call-to-action button

## Built With
- HTML5 (semantic elements, lists, blockquotes)
- CSS3 (class selectors, hover states, colors and borders)

## What I Practiced
- Structuring a multi-section landing page
- Linking sections with anchor links and IDs
- Styling cards with backgrounds, borders, and spacing

## Note
This is a practice project and is still being improved.
